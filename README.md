# Barmaja

Sitio web de Barmaja: automatización de negocios, desarrollo web y
consultoría digital.

Proyecto llevado adelante por un equipo de estudiantes universitarios de
programación.

## Estructura

- `index.html` — página principal
- `privacidad.html`, `terminos.html`, `reembolsos.html`, `cookies.html` — páginas legales
- `styles.css` — estilos (fuente de sistema de Apple, sin dependencias externas)
- `script.js` — aviso de cookies y validación de consentimiento del formulario

## Antes de publicar

Reemplazar los textos marcados como `[placeholder]` en el pie de página y
en las páginas legales con los datos reales del negocio (nombre legal,
dirección, email, teléfono) y hacer revisar los textos legales por un
profesional según la jurisdicción aplicable.
